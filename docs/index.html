Preguntas Frecuentes

Respuestas claras sobre privacidad, instalación y funcionamiento nativo en Android.

¿La aplicación es 100% gratuita y sin anuncios?
Sí. SpamZero es un proyecto de código abierto totalmente gratuito, desarrollado sin fines de lucro. No incluye anuncios publicitarios, suscripciones ocultas ni compras integradas.
¿Mis contactos o llamadas se envían a servidores en la nube?
No. La app no posee servidores propios ni envía telemetría a la nube. Toda la base de datos de patrones y la lista blanca de tus contactos se procesan localmente en el chip de tu celular.
¿Por qué Android muestra una advertencia al instalar el APK?
Android alerta automáticamente por seguridad al instalar cualquier aplicación directamente desde un archivo .APK fuera de Google Play Store. Puedes instalar SpamZero con total tranquilidad; el código fuente es público y auditable en GitHub.
¿Cómo funciona el informe probatorio para la autoridad o SERNAC?
La app permite exportar un archivo .txt con timestamps exactos, números de origen y registros de intercepción a 0 repiques. Este archivo sirve como prueba formal para realizar reclamos efectivos ante las entidades competentes.
